Detecting failures that don't throw

90 days of a support assistant, 120 requests a day. Every request in every scenario below returns 200 OK with a normal latency. Five of the six streams contain something an operator would want to know about; one does not, and is here to catch detectors that cannot tell the difference.

Each sparkline is a detector's score divided by its own alert threshold, so the dashed line at 1.0 means the same thing on every chart. Thresholds are calibrated to a 1% per-day false positive rate and an alert needs 3 consecutive days over the line. The shaded band is the 30-day reference window, inside which nothing may alert. Markers: amber = the day quality genuinely dropped; green = a correct alert; red = an alert on the control. The distance from amber to green is what this project measures.
