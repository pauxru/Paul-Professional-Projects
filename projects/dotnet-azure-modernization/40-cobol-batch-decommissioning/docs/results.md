==============================================================================
4. THE ARITHMETIC
==============================================================================
CM-BALANCE is PIC S9(7)V99. COBOL stores a computed value by truncating
toward zero; there is no ROUNDED in this program. Three plausible modern
versions of the same rule:

mode         differs     rate   on +ve   on -ve            drift
----------------------------------------------------------------
half-up         2599  51.98%     1753      846             9.07
floor           1607  32.14%        0     1607           -16.07
float           2519  50.38%     1691      828             8.63

(the corpus contains 1653 records with a negative balance, 33.1%)

==============================================================================
5. WHY THE TEST EXTRACT PASSES
==============================================================================
A tester pulls 3347 records from a quiet week — no refunds, no
credit balances — and runs all three implementations against them:

mode         differs     rate
-----------------------------
half-up         1753  52.38%
floor              0   0.00%
float           1691  50.52%

ROUND_FLOOR passes cleanly. It is the implementation you get from
`int()`, `//` or `math.floor`, it is wrong on every negative amount,
and it is invisible until the first refund run.

ROUND_HALF_UP — the version everyone would call correct — fails loudly
and immediately, which is why it never reaches production.

==============================================================================
6. SIZE ERRORS NOBODY DECLARED
==============================================================================
5000 records, 5000 balances updated, 722 silent size errors

722 records produced a balance too large for PIC S9(7)V99.
The COBOL has no ON SIZE ERROR clause, so the mainframe silently drops
the high-order digits. This harness reproduces that behaviour on purpose,
and counts it, because the alternative is a reimplementation that raises
an exception at 03:00 on a night nobody is watching.
