# Upwork Description

**Insurance Claims Modernization Lab — self-directed engineering case study**

Problem: Claims administration systems often need security, workflow, and observability improvements without risking a big-bang replacement.

Built: A runnable legacy-style MVC claims application alongside a .NET 10 modular API with EF Core, SQLite, JWT policy authorization, explicit claim state machine, document storage port, legacy anti-corruption importer, and migration/cutover documentation.

Engineering focus: characterization testing, settlement parity, SQL injection remediation, strangler routing, data reconciliation, optimistic concurrency, RFC 7807 error handling, and operational rollback.

Stack: .NET 10, ASP.NET Core, EF Core, SQLite, Npgsql adapter configuration, OpenTelemetry, xUnit.

Verification: Release build and test commands are run locally and recorded in `docs/test-results.md`.

This is a self-directed portfolio project, not client work.
