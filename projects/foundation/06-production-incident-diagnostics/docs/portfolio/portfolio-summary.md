# Portfolio Summary

Production Incident Diagnostics Lab is a self-directed engineering case study that pairs a fictional Northstar Logistics API with ten bounded broken-versus-fixed .NET incident experiments. It demonstrates how to obtain causal evidence for query fan-out, missing indexes, resource exhaustion, timeout/retry behaviour, queue poisoning, and cache coalescing without external infrastructure.

The key artefact is not a dashboard screenshot: it is executable evidence under `incidents\`, supported by tests and a transparent limits statement.
