# Upwork Portfolio Description

**Production Incident Diagnostics Lab — self-directed engineering case study**

Problem: backend teams need repeatable, safe ways to diagnose failure classes that otherwise emerge under incident pressure. Built: a .NET 10 Northstar Logistics API and harness that runs ten bounded broken-versus-fixed scenarios with real local metrics and evidence files. Engineering focus: EF query analysis, SQLite query plans, connection lifecycle, GC retention, ThreadPool behaviour, cancellation, retry budgets, dead letters, and cache single-flight. Stack: ASP.NET Core, EF Core, SQLite, OpenTelemetry, xUnit. Verification: the repository builds, tests, and regenerates local synthetic evidence without external infrastructure.

This is a self-directed portfolio project, not client work.
