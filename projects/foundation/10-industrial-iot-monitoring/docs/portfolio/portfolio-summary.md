# Portfolio Summary

Industrial IoT Monitoring Platform is a self-directed engineering case study demonstrating an independently runnable .NET 10 reference implementation for intermittent-connectivity equipment monitoring. The signature design is a hand-written MQTT 3.1.1 codec/broker/client plus a durable SQLite edge gateway that preserves local safety evaluation and ordered replay through cloud idempotency.

It is intentionally a technical demonstration using Jua Kali Manufacturing Ltd (fictional), synthetic signals, and no physical hardware.
