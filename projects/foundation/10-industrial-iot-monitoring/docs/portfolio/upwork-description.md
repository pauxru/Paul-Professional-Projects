# Upwork Description

**Industrial IoT Monitoring Platform — self-directed engineering case study**

Problem: intermittent connectivity can cause lost industrial telemetry and delayed operational visibility. Built: a .NET 10 reference implementation with a hand-written MQTT 3.1.1 TCP broker/client, durable SQLite edge store-and-forward, idempotent ingestion, typed rules/commands/twins, OTA simulation, and explainable anomaly statistics.

Engineering focus: offline recovery, protocol correctness, device identity, replay idempotency, alert flapping resistance, and observability.

Stack: .NET 10, ASP.NET Core, EF Core, SQLite, MQTT 3.1.1, JWT, OpenTelemetry, xUnit.

Verification: local build and automated tests run with no Docker, MQTT broker, cloud service, or physical hardware.

This is a self-directed portfolio project, not client work.
