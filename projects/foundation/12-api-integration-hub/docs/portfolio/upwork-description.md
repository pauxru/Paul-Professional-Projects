# Upwork Portfolio Description

## API Integration Hub — self-directed engineering case study

**Problem:** CRM, ERP, and payment systems often expose incompatible contracts and unreliable behavior, while one-off scripts provide weak recovery and visibility.

**Built:** A .NET 10 integration hub with versioned connectors, declarative JSON/YAML flows, safe field mappings, scheduling, contract-drift detection, encrypted secrets, execution history, checkpoints, and idempotent dead-letter replay.

**Engineering focus:** OAuth refresh, four pagination modes, `Retry-After`, circuit breaking, bulkheads, HMAC replay defense, mapping sandboxing, PII/secret redaction, and realistic in-repository API simulators.

**Stack:** ASP.NET Core, EF Core, SQLite, OpenTelemetry, xUnit, HTML/JavaScript.

**Verification:** Release build and automated unit/integration tests run with no external infrastructure or outbound calls.

This is a self-directed portfolio project, not client work.
