# Upwork Description

**Loan Origination & Credit Workflow Platform — self-directed engineering case study**

Problem: credit operations need decisions that can be reproduced and explained after policy, product, and reviewer changes.

Built: a .NET 10 loan-origination reference implementation with SQLite, versioned products and declarative rules, transparent affordability and scorecard calculations, document/KYC workflow, delegated underwriting, immutable offers, and idempotent disbursement simulation.

Engineering focus: explainability traces, money rounding, IRR/APR, ruleset what-if analysis, four-eyes approval, auditability, timeout recovery, and zero-infrastructure testability.

Verification: unit and SQLite in-memory HTTP integration tests are recorded in `docs/test-results.md`.

This is a self-directed portfolio project, not client work.
