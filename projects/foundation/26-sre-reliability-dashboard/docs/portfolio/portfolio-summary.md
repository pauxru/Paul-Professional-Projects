# Portfolio Summary

Northstar Reliability Control Room is a self-directed engineering case study focused on correct SLO mathematics rather than dashboard aesthetics. It demonstrates a .NET 10 modular monolith with SQLite, deterministic telemetry simulation, declarative SLI/SLO evaluation, multi-window burn-rate alerting, incident learning loops, and a deploy-gate API.

The distinctive evidence is in `docs/slo-mathematics.md` and the hand-built test fixtures: thresholds, duration, budget spend, recovery, and suppression are explicit rather than implied.
