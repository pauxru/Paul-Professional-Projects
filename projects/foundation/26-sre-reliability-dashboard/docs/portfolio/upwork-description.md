# Upwork Portfolio Description

**Northstar Reliability Control Room — self-directed engineering case study**

Problem: engineering teams need defensible SLO/error-budget decisions and low-noise alerts, not a decorative monitoring page. Built: a .NET 10 reference implementation with SQLite, synthetic telemetry, multi-window burn-rate alerting, incident/postmortem workflows, and a deploy-gate API. Engineering focus: hand-verifiable SLO arithmetic, state-machine correctness, policy enforcement, and no-infrastructure reproducibility. Verification: unit and SQLite in-memory integration tests cover calculations and HTTP authorization/validation.

This is a self-directed portfolio project, not client work.
