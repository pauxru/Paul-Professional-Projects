# Portfolio Summary

Northstar Cloud Cost & Observability Platform is a self-directed engineering case study demonstrating a production-style FinOps workflow without external cloud infrastructure. It focuses on exact cost allocation, provider-independent idempotent ingestion, measured forecasts/anomaly detection, and verified savings rather than dashboard polish alone.

The implementation is a .NET 10 modular monolith with EF Core/SQLite, JWT policy authorization, OpenTelemetry, and a dependency-free SVG dashboard. Its synthetic data models four subscriptions, nine teams, 400 resources, more than 250,000 cost rows, shared services, missing tags, and known cost behavior.
